🛠️ 시스템 업데이트 노트

[Ver 3.0.01] 업데이트 내역

  • 1. 뉴스 및 북마크 게시판 생성 적용.
  • 2. 대부분의 게시물 카톡 공유 적용.(웹에서 바로 공유 가능)
  • 3. Today이슈 & 뉴스 06시~21시까지 네이버, 네이트, 다음 뉴스 검색 보험/건강뉴스 갈무리 기능 제공. 약간의 문장만 적용 기사 내용 각 포털 사이트로 연결됨.
  • 4. 보험상품이자계산기 프로그램 제작/출력기능 결과값 카톡전송기능제공

[Ver 3.000] 업데이트 내역

  • 팩스서버 구성 및 지점별 팩스 서버 관리 솔루션 구성완료

[Ver 3.000] 업데이트 내역

  • 전체적으로 디자인을 카드형으로 변경
  • 1. 회원가입 기능(최소한의 정보 데이터 암호화)
  • 2. 기존 링크를 최신 버전으로 전부 수정함.
  • 3. 청구서와 관련 자료 모두를 업데이트함.
  • 4. 각 보험사의 전산 설치 및 전산 사용 매뉴얼 등록
  • 5. 모바일청약 업데이트
  • 6. 신용카드 결제 업데이트
  • 7. 본부연락처 추가 기능
  • + 본인 소속의 원수사 지점장/총무/설계매니저 등록가능(본부장, 지점장, 총무가 등록(유료기능))
  • + 원수사 전산 본인 코드 및 비번 저장 기능
